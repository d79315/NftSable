# NftSable

NftSable orchestrates dynamic data workflows with real-time processing and auto-scaling, serving as a high-performance Service Manager.

NftSable is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftSable.git`
2. `cd NftSable`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NftSable, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
